# Getting Started with Open5GS Roaming

Welcome to the getting started guide for the Open5GS Roaming project! This section will walk you through the initial setup and configuration needed to create your own 5G roaming environment using Docker and MicroK8s.

## Prerequisites

Before you begin, make sure you have the following installed on your system:

- Docker and Docker Compose
- MicroK8s
- Git
- Vagrant
- A system with at least 8GB RAM and 4 CPU cores

## Overview of the Setup Process

Setting up a 5G roaming environment involves several key steps:

1. **Environment Preparation**: Setting up your host machine with the necessary tools
2. **Network Configuration**: Creating the virtual networks that will connect your components
3. **Deploying Home Network**: Setting up the first Open5GS instance as your home network
4. **Deploying Visited Network**: Setting up the second Open5GS instance as your visited network
5. **Configuring Roaming Relationships**: Establishing the connections between networks
6. **Testing Connectivity**: Verifying that roaming works as expected

In the following sections, we'll dive deeper into each of these steps, providing detailed instructions and explanations along the way.

Let's get started with building your 5G roaming environment!
