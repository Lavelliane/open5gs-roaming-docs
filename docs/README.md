# Open5gs Roaming on Docker and MicroK8s

> This project demonstrates how to set up a 5G roaming environment using Open5GS on Docker and MicroK8s. It provides a comprehensive guide for implementing and testing roaming capabilities between two simulated mobile networks, allowing developers and network engineers to understand and experiment with 5G roaming protocols in a containerized environment.

**Authors:** Jhury Kevin Lastre and Vincent Abella

## Welcome!

Hey there! We're excited that you've found our Open5GS Roaming project. We've put together this guide to help you navigate the sometimes complex world of 5G roaming in a way that's approachable and practical.

Whether you're a network engineer looking to understand roaming protocols better, a developer wanting to experiment with 5G technologies, or just curious about how mobile networks talk to each other, we've got you covered.

This project started from our own journey of learning and experimenting with 5G technologies, and we wanted to share what we've discovered along the way. We've tried to make everything as straightforward as possible, but if you get stuck or have questions, feel free to reach out!

Let's dive in and build some awesome 5G roaming setups together!
