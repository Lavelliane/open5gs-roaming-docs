Overview

This documentation guides you through setting up a complete Open5GS environment with roaming capabilities. The setup includes two networks (Home and Visiting) with all the necessary components for 5G core functionality.

The Open5GS Roaming setup demonstrates how 5G roaming works between two network operators using Docker containers. Each component of the 5G core is containerized, making it easy to deploy and test.

Quick Start

Start with the Environment Setup section to prepare your system.

Note: This setup requires Ubuntu 22.04 or compatible Linux environment with Docker support and kernel modules for GTP5G. If you're using Windows or macOS, you'll need to set up a virtual machine with Ubuntu 22.04.
